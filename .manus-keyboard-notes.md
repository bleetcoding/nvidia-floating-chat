# Keyboard and notification feature findings

The screenshots show that Gboard, rather than the registered Floating AI Keyboard input method, is currently selected. Android requires the user to select an enabled input method; the app will add an explicit selection diagnostic and picker shortcut.

The custom Android input method already has direct `InputConnection` access for replacements. Its toolbar will be rebuilt around Translation, Rewrite, Reply, Grammar, Undo, and Redo. Automatic screen context remains text-only and opt-in; intentional image attachments will be routed through the existing multimodal provider payload support.
